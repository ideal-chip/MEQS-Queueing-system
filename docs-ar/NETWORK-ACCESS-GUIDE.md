### 5️⃣ الكشك - Kiosk API

**الرابط الرئيسي:**
```
http://192.168.1.72:8000/beaa/api/kiosk/get.php?id=1
```

**الوصف:**
واجهة API للتكامل مع أجهزة الكشك لإصدار التذاكر.

**API Endpoints:**

#### الحصول على إعدادات الكشك:
```
GET http://192.168.1.72:8000/beaa/api/kiosk/get.php?id=1
```
يعرض قائمة الفئات المتاحة وإعدادات الكشك.

#### إصدار تذكرة واحدة:
```
GET http://192.168.1.72:8000/beaa/api/kiosk/set.php?id=1&cat=1&lang=ar
```
Parameters:
- `id` - رقم الكشك (1)
- `cat` - رقم الفئة (1 أو 2)
- `lang` - اللغة (ar أو en)

#### إصدار عدة تذاكر (Bulk):
```
GET http://192.168.1.72:8000/beaa/api/kiosk/set-bulk.php?id=1&cat=1&qty=3&lang=ar
```
Parameters:
- `qty` - عدد التذاكر (1-10)

#### آخر تذكرة مطبوعة:
```
GET http://192.168.1.72:8000/beaa/api/kiosk/lastprinted.php?id=1
```

**مثال استخدام curl:**
```bash
# إصدار تذكرة فئة "خدمة العملاء"
curl "http://192.168.1.72:8000/beaa/api/kiosk/set.php?id=1&cat=1&lang=ar"

# إصدار 3 تذاكر فئة "المعاملات المالية"
curl "http://192.168.1.72:8000/beaa/api/kiosk/set-bulk.php?id=1&cat=2&qty=3&lang=ar"
```

## 🛠️ استكشاف الأخطاء

### المشكلة: لا يمكن الوصول من الشبكة

**الحل:**
```bash
# تأكد من أن السيرفر يعمل على 0.0.0.0 وليس 127.0.0.1
netstat -tuln | grep :8000
# يجب أن ترى: 0.0.0.0:8000

# إذا كان 127.0.0.1:8000، أعد التشغيل:
cd /home/idealchip_server/meqs
bash scripts/stop_local_runtime.sh
bash scripts/start_local_runtime.sh
```

### المشكلة: Firewall يحجب المنفذ 8000

**الحل:**
```bash
# إذا كان لديك صلاحية sudo
sudo ufw allow 8000/tcp
# أو
sudo iptables -A INPUT -p tcp --dport 8000 -j ACCEPT
```

### المشكلة: لا يمكن تسجيل الدخول

**الحل:**
1. تأكد من كتابة البريد الإلكتروني كاملاً
2. كلمات المرور حساسة لحالة الأحرف (Case-sensitive)
3. تأكد من تشغيل قاعدة البيانات

### المشكلة: الشاشة الكبيرة لا تظهر التذاكر

**الحل:**
1. تأكد من وجود تذاكر في النظام
2. جرب إصدار تذكرة جديدة من الكشك
3. تحقق من أن Display updated = 1

## 🚀 الوصول من الإنترنت (خارج الشبكة المحلية)

لجعل النظام متاحاً من الإنترنت، تحتاج إلى:

1. **Port Forwarding على الراوتر:**
   - افتح إعدادات الراوتر
   - أضف Port Forwarding من Port 80 → 192.168.1.72:8000
   - أو من Port 443 → 192.168.1.72:8000 (مع SSL)

2. **Dynamic DNS (إذا لم يكن لديك IP ثابت):**
   - استخدم خدمة مثل No-IP أو DuckDNS
   - احصل على domain مجاني مثل: `yourcompany.ddns.net`

3. **SSL Certificate (للأمان):**
   - استخدم Let's Encrypt للحصول على شهادة مجانية
   - أو استخدم Cloudflare Tunnel

**تحذير أمني:** لا تنشر النظام على الإنترنت بدون:
- HTTPS/SSL
- تغيير كلمات المرور الافتراضية
- تفعيل Firewall
- إضافة CSRF Protection
