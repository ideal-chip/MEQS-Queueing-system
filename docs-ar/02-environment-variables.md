# 02 - متغيرات البيئة

تمت إضافة `.env.example` آمن. لا يتم تضمين أسرار إنتاج.

| الاسم | الاستخدام | مطلوب؟ | مثال آمن |
|---|---|---:|---|
| `APP_ENV` | يوضح بيئة التشغيل | لا | `local` |
| `APP_BASE_URL` | رابط التطبيق المستخدم في التوثيق والاختبار | لا | `http://127.0.0.1:8000` |
| `DB_HOST` | مضيف MySQL | نعم | `localhost` |
| `DB_PORT` | منفذ MySQL | لا | `3306` |
| `DB_NAME` | اسم قاعدة البيانات | نعم | `project_demo_db` |
| `DB_USER` | مستخدم قاعدة البيانات | نعم | `project_demo_user` |
| `DB_PASSWORD` | كلمة مرور مستخدم قاعدة البيانات | نعم | `ProjectDemo@12345` |
| `PHP_SERVER_HOST` | عنوان السيرفر المحلي | لا | `127.0.0.1` |
| `PHP_SERVER_PORT` | منفذ السيرفر المحلي | لا | `8000` |

## ملاحظة أمنية
كان الاتصال بقاعدة البيانات مكتوباً داخل ملفات PHP مباشرة. تم تعديل ملفات الاتصال الأساسية لتقرأ من `.env` أو environment variables.
