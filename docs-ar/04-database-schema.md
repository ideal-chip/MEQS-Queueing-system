# 04 - توثيق مخطط قاعدة البيانات

المخطط موجود في `database/schema.sql`.

## الجداول الأساسية
- `users`: مستخدمو لوحة الإدارة. أهم الأعمدة: `user_name`, `user_password`, `user_privileges`.
- `clerks`: موظفو الكاونتر. مرتبط بـ `zones`.
- `zones`: مناطق/صالات الخدمة.
- `categories`: فئات التذاكر والخدمات. مرتبط بـ `zones`.
- `subcategories`: خدمات فرعية ومتابعات مرتبطة بـ `categories`.
- `texts`: ترجمات النصوص بحسب اللغة والمفتاح.
- `settings`: إعدادات النظام مثل اللغة الافتراضية وعدد خانات التذكرة.
- `counters`: الكاونترات. مرتبط بـ `displays`, `audios`, `zones`.
- `countercategories`: ربط الكاونتر بالفئات المسموحة.
- `kiosks`: أجهزة إصدار التذاكر.
- `kioskbuttons`: أزرار الكشك وربطها بالفئات.
- `displays`: الشاشات العادية.
- `bigdisplays`: الشاشات الكبيرة.
- `bigdisplaytypes`: أنواع الشاشات الكبيرة.
- `bigdisplayscounters`: ربط الشاشات الكبيرة بالكاونترات.
- `bigdisplayforcounter`: إعداد شاشة خاصة لكاونتر.
- `bigdisplayservices`: إعداد خدمات الشاشة الكبيرة.

## جداول الحركة
- `events`: التذاكر الصادرة.
- `events_logs`: سجل نداءات ومعالجة التذاكر.
- `counters_logs`: دخول/خروج موظفي الكاونتر.
- `displays_logs`: ما يظهر على الشاشات.
- `audios_logs`: سجل النداءات الصوتية.
- `audios_logs_bulk`: سجل الصوت للنداء الجماعي.
- `transfers`: تحويل التذاكر بين كاونترات/فئات.
- `followups`: بطاقات متابعة العملاء.
- `feedback`: تقييمات العملاء.

## الفهارس والعلاقات
تمت إضافة مفاتيح أساسية وفهارس للعلاقات الأكثر استخداماً: الفئة، المنطقة، الكاونتر، الشاشة، وسجلات اليوم. بعض العلاقات في الكود القديم كانت ضمنية؛ في schema الديمو تم تحويلها إلى foreign keys حيث أمكن.
