# 10 - تقرير الاختبارات

## الاختبارات الموجودة
لم أجد اختبارات أصلية.

## ما تمت إضافته
تمت إضافة `tests/smoke.sh` للتحقق من:
- وجود PHP.
- وجود curl.
- وجود MySQL client.
- اتصال قاعدة البيانات.
- تحميل الصفحة الرئيسية وصفحة login وصفحة counter.

## نتيجة التشغيل في هذه البيئة
فشل الاختبار لأن البيئة لا تحتوي:
- `php`
- `mysql`

كما لم يكن هناك server محلي يعمل، لذلك أرجعت curl كود `000`.

## أمر التشغيل
```bash
BASE_URL=http://127.0.0.1:8000 tests/smoke.sh
```

## تحقق يدوي مطلوب
بعد تثبيت PHP/MySQL وتشغيل السيرفر، يجب اختبار:
- دخول admin.
- دخول operator من صفحة الكاونتر.
- إصدار تذكرة من kiosk API.
- ظهور التذكرة على display/bigdisplay.
